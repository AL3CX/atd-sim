# AI-Assisted Targeting Dilemma Simulator (ATD-SIM)
## Overview
This simulator is designed to help users understand the ethical and legal implications of using AI in military applications, specifically in the context of selecting targets which is actively being used today. 

## Content Warning
The content of this simulator may be distressing to some individuals, as it includes discussions related to the ethical dilemmas of AI-assisted targeting that are linked with **real-world** military operations.

**CW Tags**: Military Violence, Moral Injury
